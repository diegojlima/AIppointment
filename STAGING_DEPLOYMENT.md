# AIppointment Staging Environment Setup

This document outlines the steps for setting up and validating the AIppointment staging environment.

## Prerequisites

- AWS CLI configured with the appropriate credentials
- Terraform installed locally
- Python 3.8+ installed
- Proper access to AWS services:
  - AWS Bedrock
  - AWS Lambda
  - Amazon DynamoDB
  - AWS IAM
  - Amazon API Gateway
  - Amazon S3
  - AWS
